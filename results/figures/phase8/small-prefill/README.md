# Phase 8 small-prefill results

This directory contains plots for the fixed-budget 256-history + 32-new-token interference experiment. PNG files are suitable for GitHub previews; SVG/PDF are provided for scalable export. `plot-data.json` is the portable audited snapshot and `generate.py` recreates all plots without inference.

The source evidence and audit live under `artifacts/phase8-small-prefill-evidence/` and `artifacts/phase8-small-prefill-analysis/`. See `docs/TWO_NODE_PHASE8_SMALL_PREFILL.md` for workload definitions, validation, and interpretation.
